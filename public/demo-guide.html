A complete test

  1. Sign in as the driver. Choose Towing and the saved truck. Use Bakersfield for the test location.
  2. Submit the request. Use separate browser profiles or sign out to switch roles.
  3. Sign in as the provider dispatcher. Open Live Leads, unlock the request, and send a $500 quote with a 35-minute ETA.
  4. As the driver or fleet office, open the request and choose the company.
  5. As the dispatcher, open Jobs and assign Demo Technician.
  6. As the technician, accept, set an ETA, mark arrived and complete.
  7. As the fleet office, review the request and export the CSV. Try assigning a vehicle to another invited driver.
  8. As administrator, inspect sales, a credit refund and System status.

In production, demo accounts must not be seeded. See START-HERE.md in the project for the API keys and deployment setup. This is a responsive web app/PWA; native app-store builds still require device integration, signing and review.
